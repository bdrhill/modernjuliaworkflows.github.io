# Deploying Julia — source transcripts

Source material for the [Deploying your code](../../src/deployment/index.md) page.

- **Talk:** “Lessons in deploying Julia to production services” by Avik Sengupta (JuliaHub, Inc.), JuliaCon Global 2026.
- **Video:** <https://www.youtube.com/watch?v=myZAp6vSgQA>
- **Permission:** the talk contents are reused with the speaker’s permission.

## Files

- [`voice.md`](voice.md) — machine-generated transcript of the spoken audio, with chapter headings and timestamps. Produced with OpenRouter speech-to-text (`openai/whisper-large-v3`). Filler words and recognition errors are preserved; see the recognition notes at the top.
- [`slides.md`](slides.md) — transcript of the text visible on the slides, with approximate slide start times. Frames were extracted from the video and transcribed with OpenRouter vision (`google/gemini-3.5-flash`), then checked by hand.

These files are reference material for the site and are not part of the Zola build.
